# 계란 타이머 (egg-timer)

반숙이나 완숙만 고르면 삶는 시간을 재고 알람으로 알려주는 웹앱(PWA)입니다.

**데모: https://spica07.github.io/egg-timer/**

## 기능

- **버튼 두 개**: 반숙과 완숙만 있습니다. 계란 크기나 개수를 입력하는 단계가 없습니다.
- **끓는 물 / 찬물 고르기**: 끓는 물에 넣고 시작하면 반숙 7분, 완숙 12분입니다. 찬물부터 삶으면 물이 끓기까지 2분을 더해 반숙 9분, 완숙 14분으로 잡습니다.
- **화력 차이 바로잡기**: 찬물부터 삶을 때는 화력과 냄비에 따라 끓는 시간이 크게 달라집니다. 삶는 화면의 `물이 끓기 시작했어요`를 누르면 그 순간부터 삶는 시간을 다시 잡아 오차를 없앱니다. 끓기 전까지는 계란도 익지 않은 모습으로 그대로 있습니다.
- **익어가는 계란 단면**: 남은 시간을 원형 막대가 아니라 계란 단면으로 보여줍니다. 실제 계란처럼 노른자가 겉에서 안으로 익고, 흰자는 앞쪽 구간에서 먼저 불투명해집니다. 정확한 숫자는 아래 `분:초`로 함께 표시합니다.
- **화면 꺼짐 방지**: 삶는 동안 Screen Wake Lock으로 화면을 켜둡니다. 지원하지 않는 브라우저에서는 안내 문구로 대신합니다.
- **확실한 알람**: 타이머를 시작하는 순간 종료 시각의 알람음을 오디오 그래프에 미리 예약합니다. 오디오 클럭은 자바스크립트 타이머와 별도로 흐르기 때문에, 탭이 백그라운드로 밀려 `setInterval`이 스로틀링돼도 소리가 납니다. 진동을 지원하는 기기에서는 함께 울립니다.
- **어긋나지 않는 카운트다운**: 남은 시간을 깎아나가는 방식이 아니라 절대 종료 시각에서 매번 다시 계산합니다. 다른 앱을 보다 돌아와도 시간이 맞습니다.
- **내 기준으로 저장**: 삶는 화면의 `−30초 / +30초`로 조절한 값은 다음 실행의 기준이 됩니다. 화력이나 계란 크기에 맞춰 자기 기준을 만들 수 있습니다.
- 오프라인에서도 열리도록 PWA로 설치할 수 있습니다.

## 기술 스택

빌드 도구 없이 순수 HTML/CSS/JavaScript로만 만들었습니다. 계란 단면은 SVG, 알람음은 Web Audio API로 만듭니다.

```
egg-timer/
├── index.html
├── manifest.json      # PWA 매니페스트
├── sw.js              # 오프라인 캐싱용 서비스워커
├── assets/
│   ├── css/style.css
│   └── js/
│       ├── egg.js      # 계란 단면 익힘 렌더링
│       ├── timer.js    # 절대 시각 기반 카운트다운
│       ├── alarm.js    # 알람음 예약·재생, 진동
│       └── app.js      # 화면 전환, 기준 시간, Wake Lock
└── icons/
```

## 로컬에서 실행하기

```
py -m http.server 8000
```

이후 브라우저에서 `http://localhost:8000` 접속.

12분을 기다리지 않고 흐름을 확인하려면 `http://localhost:8000/?test=1`로 접속합니다. 반숙 5초, 완숙 8초, 찬물 끓이는 시간 4초로 바뀝니다.

서비스워커가 캐시 우선으로 동작하므로, 파일을 고쳤는데 반영되지 않으면 `sw.js`의 `CACHE_NAME` 버전을 올리세요. 배포할 때도 마찬가지입니다.

## 삶는 시간 기준

냉장고에서 꺼낸 보통 크기(약 50g) 계란 기준입니다.

| | 끓는 물에 넣기 | 찬물부터 삶기 | 상태 |
|---|---|---|---|
| 반숙 | 7분 | 9분 | 노른자가 촉촉하게 흐름 |
| 완숙 | 12분 | 14분 | 노른자까지 단단하게 익음 |

찬물 쪽 시간은 물이 끓기까지 2분을 더한 값입니다. 화력이 약하거나 물이 많으면 더 오래 걸리니, 실제로 끓는 순간에 `물이 끓기 시작했어요`를 누르는 게 가장 정확합니다.

계란 개수와 냄비 크기에 따라서도 달라지니 `−30초 / +30초`로 자기 기준을 맞춰 쓰세요. 조절값은 삶는 시간에 저장되어 끓는 물과 찬물 양쪽에 함께 반영됩니다.
